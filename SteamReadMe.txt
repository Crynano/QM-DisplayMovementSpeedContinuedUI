[h1] Display Movement Speed Continued - UI [Hover Version] [/h1]

This version of Display Movement Speed mod shows UI when hovering over an enemy.

The UI features a health bar, an icon for melee/ranged enemy and action points remaining.

All of these options can be toggled on and off in the config file. File location is listed under the category "Config" below.


[h2] Continued Notes [/h2]
This mod is a version of the Continued mod by [url=https://github.com/NBKRedSpy]NBK_RedSpy[/url]

[h2] Config [/h2]
To rebind the comma key toggle, go to:
`%UserProfile%\AppData\LocalLow\Magnum Scriptum Ltd\Quasimorph_ModConfigs\QM_DisplayMovementSpeedUI\config.json`
and change "Comma" [url=https://docs.unity3d.com/ScriptReference/KeyCode.html]with a Unity Keycode of your choice (scroll down to the Properties section)[/url]
