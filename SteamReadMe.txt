[h1] Display Movement Speed Continued - UI [Permanent Version] [/h1]
This version of Display Movement Speed mod shows UI on every visible enemy.

The UI features a health bar, an icon for melee/ranged enemy and action points remaining.

All of these options can be toggled on and off in the config file. Location is listed under the category "Config" below.

[h2] **Important!** [/h2]
Make sure you are not subscribed to neither the original Display Enemy Movement Speed mod or the Continued version, or this mod will not work correctly.

[h1] Continued Notes [/h1]
This mod is a version of the Continued mod by [b]NBK_RedSpy[/b] (https://github.com/NBKRedSpy).
We are maintaining different versions of it for user preference.

At the same time, a continuation of GitHub user [b]jamsge's[/b] (https://github.com/jamsge) mod.

If needed, the mod will be taken down upon original author's request.

[h2] Config [/h2]
To rebind the comma key toggle, go to:
`%UserProfile%\AppData\LocalLow\Magnum Scriptum Ltd\Quasimorph_ModConfigs\QM_DisplayMovementSpeedUI\config.json`
and change "Comma" [with a Unity Keycode of your choice (scroll down to the Properties section)](https://docs.unity3d.com/ScriptReference/KeyCode.html).

Here you can also change each element of the UI to true or false.
